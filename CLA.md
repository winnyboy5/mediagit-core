# Contributor License Agreement

Thank you for wanting to contribute to MediaGit.

Before your first pull request can be merged, we need you to agree to this
Contributor License Agreement ("CLA"). It is short, and this page explains why it
exists before it asks you for anything.

## Why this exists

MediaGit is [source available under BUSL-1.1](LICENSE) and is also offered under a
[commercial licence](LICENSE-COMMERCIAL.md). Offering the same code under two sets
of terms is only legally possible if one party holds the rights to all of it.

If you contribute code and keep full copyright in it, then that code can only ever
be distributed under BUSL-1.1 — nobody, including the maintainer, could include it
in a commercially licensed build. One merged pull request without an agreement in
place would quietly make the commercial licence unsellable for the file it touched,
permanently and irreversibly.

This CLA solves that. It is the same instrument used by Google, Apache, .NET and
most dual-licensed projects.

**It does not take your copyright away.** You keep it, and you may use your own
contribution however you like, including in other projects under any licence.

## How to sign

Open a pull request. An automated check will ask you to confirm this CLA on the
pull request itself, once. It applies to that and all future contributions.

If the automated check is not available, add this line to your pull request
description:

```
I have read the CLA and I hereby sign it.
```

## Questions

If any of this is unclear or you cannot agree to part of it, open an issue or
email **licensing@mediagit.dev** before writing code. It is much easier to sort
out beforehand than after a pull request is already open.
